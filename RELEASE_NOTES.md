# Release Notes — v1.1.0

Опис змін у версії **v1.1.0** порівняно з **v1.0.0**.

## Added
- Додано спеціальний базовий тариф доставки **80.0** для міста `"Kyiv"`.
- Додано явний параметр ставки податку `tax_rate` (зі значенням за замовчуванням `0.20`) у функцію розрахунку стандартного рахунку.

## Changed
- Коефіцієнт вартості доставки за вагу збільшено з **12.0** до **15.0** за кілограм.
- Виконано рефакторинг архітектури модуля: здійснено перехід від високої зв'язаності (Common, Stamp, Control Coupling) до слабкої зв'язаності через передачу примітивних даних (**Data Coupling**).

## Breaking Changes
- Змінено сигнатури функцій розрахунку: тепер замість об'єкта `CustomerProfile` приймається виключно рядок `city: str`.
- Повністю видалено глобальну змінну `GLOBAL_TAX_RATE`.
- Видалено керуючий прапорець `mode_flag`; єдину функцію `process_invoice` розділено на дві окремі: `process_standard_invoice` та `process_tax_exempt_invoice`.
